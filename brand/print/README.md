# Bookeyond Kid — print and partner artwork

Outlined vector files: no font needed to open, print or place them.

| File | Use |
|---|---|
| `bookeyond-kid-logo-ink.svg` / `.pdf` | Mark + wordmark on light grounds |
| `bookeyond-kid-logo-paper.svg` | Mark + wordmark on dark grounds (Tonle Night `#0A1533` or darker) |
| `bookeyond-kid-wordmark-ink.svg` / `.pdf` | Wordmark alone on light grounds |
| `bookeyond-kid-wordmark-paper.svg` | Wordmark alone on dark grounds |
| `bookeyond-kid-mark-ink.svg` | The mark alone, 36px / 10mm and larger |
| `bookeyond-kid-mark-small-ink.svg` | The simplified mark for anything smaller (favicons, stamps, small print) |

- "Bookeyond" is Bricolage Grotesque at weight 750, "Kid" at 420 (optical size 48), with the
  logo's tracking and kerning, outlined from the self-hosted font the app ships
  (`frontend/node_modules/@fontsource-variable/bricolage-grotesque`, SIL Open Font License).
- Colours: Bookeyond `#11214D`, Kid `#4468B8`; on dark `#FFFFFF` and `#C9D6EF`. Spark `#F3A83B`.
- Keep clear space of at least the spark's height around the logo. Don't recolour the spark,
  stretch, outline or add effects. Rules in `DESIGN.md`.
- Colours are defined for screen (sRGB). A printer's CMYK/Pantone match has not been proofed.
