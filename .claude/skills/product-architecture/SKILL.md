# Product Architecture
Protect the Bookeyond product thesis.

Core: Adaptive Engine, Progression, Parent Insight, Smart Review.
Learning loop: Content → Path → Activity → Question → Evidence → Mastery → Decision/Review/Progression/Insight.

Parent value must be grounded in actual evidence and explain “why am I seeing this?”. Completion is not mastery.

Do not introduce AI-like child conversation, engagement-maximizing mechanics, leaderboards, currencies, ads, social/UGC, or premature school ERP without explicit product approval.

If a gap is a product decision rather than a technical defect, stop and surface it.
