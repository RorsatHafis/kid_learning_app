# Performance and Reliability
Use when latency, scale, concurrency, retries, or resource use matter.

Inspect query count/N+1, indexes, pagination, caching correctness, transaction duration, connection usage, request cancellation/timeouts, retry storms, idempotency, duplicate work, and frontend bundle/render cost.

Optimize from evidence. Do not add caching, async processing, queues, or microservices speculatively.
