# Backend Quality
Review backend changes for correctness beyond compilation.

Check: domain invariants, null/empty cases, concurrency, transaction atomicity, retries/idempotency, pagination/order, authorization, DTO leakage, N+1/query behavior, migration compatibility, rollback implications, observability, and backward compatibility.

Do not accept “looks correct.” State what was inspected, what was executed, and what remains unverified.
