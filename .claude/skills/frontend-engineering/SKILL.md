# Frontend Engineering
Use for React/TypeScript/Vite implementation.

Treat backend contracts as authoritative. Trace route → state → API client → response mapping → UI → mutation → refresh/error state.

Use typed models, predictable state transitions, reusable primitives, explicit loading/empty/error/success states, cancellation where needed, accessible controls, keyboard support, responsive layouts, and resilient network behavior.

Do not duplicate security or learning decisions in the client. Do not hide API failures with fake success states.
